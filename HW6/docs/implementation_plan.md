# HW6 實作與驗收計畫

規格：`../job.md`。以 Python 標準函式庫計算，使用 uv 專案環境；全部新增檔案位於 HW6，不修改原始附件或其他作業。
使用者已要求依完整規格直接實作，採本工作目錄執行，不另建 worktree、不自動提交。

- [x] 先寫獨立手算期望值的測試，確認尚未實作時失敗。測試保護重複抽樣計數、回到原始資料計算 ε、權重傳遞、切分點等號及最終投票。
- [x] `src/adaboost.py` 以通用函式評估六規則、執行三輪，輸出 `results/` 的 JSON、CSV 及 console 摘要。
- [x] 同一份結果產生 `report/sections/` 中的 LaTeX 表格與計算式；`report/worksheet.tex` 為完成版學習單，`report/main.tex` 為含方法及驗證說明的主報告。
- [x] 使用既有 tectonic 編譯兩份 PDF；以本機 PDFKit 逐頁轉成圖片檢視，檢查頁數、字型、表格、交叉引用及題號。
- [x] 從頭重跑程式與所有測試，核對八項驗收清單，記錄於 `docs/verification.md`。

選擇：不用 scikit-learn，因本題需指定抽樣清單及限制候選規則；不用隨機抽樣。學習單採可直接繳交的 PDF，原 DOCX 唯讀。顯示取六位小數，中間運算保留雙精度；沒有同分或零投票案例，程式同分取 A–F 先出現者，零投票回傳 0。
